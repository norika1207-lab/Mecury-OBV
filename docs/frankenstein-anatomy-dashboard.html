Current Meaning
妳現在拿到的是模型解剖資料，不再只是展示圖。

這些 fullgrid 可以開始做跨模型熱區、共同骨架、fine-tune 改變、merge 損傷與可抽取區域分析。

之前被包裝成成果，但不能算「完整打開」

  • Head-level 5 維 fingerprint：只能看 attention head 摘要。
  • Layer fingerprint：只能看層級輪廓，不知道每個 tensor/channel。
  • Coverage 低於 90% 的 grid：不能拿來說每個角落看清楚。
  • 非 per-channel quantile：會把不同 channel 的尺度混在一起。
  • First-packet / cache replay：是 workflow 加速，不是模型內部解剖。
  • model_inside_unavailable 卻標 pass：是產品殼，不是模型內部成功。

現在可以算真的拿到的東西

  • 14 筆達標 fullgrid run：100M+ cells、90%+ coverage、per-channel=True。
  • 11 個 unique model，跨 GPT / OPT / Pythia / Phi / Gemma / Qwen / InternLM。
  • Qwen2.5 7B Base continuity 結論：attention topology path + late residual carry。
  • merge benchmark contrast：DARE-TIES 70%，TIES 30%，可接 fullgrid 解釋。
  • 明確品質閘門：head/layer/低 coverage 一律不混入成果。

Data Quality Gate

這是防騙欄
資料類型可否算成果原因處理方式
100M+ fullgrid / 90%+ / per-channel可算足夠接近完整解剖標準進 atlas、compare、surgery
Coverage 低於 90%不可算角落沒有看清楚重跑或只當失敗紀錄
Head-level fingerprint不可算降維摘要，不能代表全部神經元可作輔助，不進 completion
Layer fingerprint不可算只看層，不看 tensor/channel/seq可作粗索引
First-packet / cache replay不可算是 workflow，不是模型內部 anatomy歸到產品加速，不混入研究成果
Continuity probe可當 targeted analysis回答特定能力路徑，不是 fullgrid completion和 fullgrid 對齊後做 causality
