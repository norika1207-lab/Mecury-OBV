核心設計

Mercury 不是把所有問題都丟給 LLM。它先像神經反射一樣判斷：能不能用快取、確定性工具、專案記憶、symbol table、已驗證 workflow 直接得到第一個有用訊號。

1. Sensory Layer讀 host、CPU、記憶體、GPU、provider、spend guard、repo 狀態。
2. Reflex Arcexact cache、semantic cache、已蒸餾答案與低風險快速回覆。
3. Synapse Memoryproject UMA namespace、RAG pages、hot pages、task memory、provider cache。
4. Neuron Map200 個實體神經元，分到 goal、surface、risk、verify、memory、synthesis 等 lanes。
5. Muscle LayerCLI、resident HTTP、doctor、monster-doctor、accelerate-task、bench runner。
6. Slow BrainQwen/Ollama/frontier model 只做慢路徑與蒸餾，不准卡住 hot path。

後續開發進度

Phase 2A: 真冷啟動加速

  • first-gen 不是只切 sections，要能把 evidence packet 直接轉為可交付草稿。
  • 建立 draft quality judge，不讓快速草稿變成低品質輸出。
  • 把 slow model 結果自動蒸餾成 reusable route、reflex、UMA lesson。

Phase 2B: Windows/Qwer Laptop

  • 在 NVIDIA 筆電建立 resident control plane。
  • Qwer/Ollama 走 slow refresh，前台只用 reflex/UMA/tool kernels。
  • game/low-power mode：玩遊戲時禁止 broad scan 與模型 hot path。

Phase 2C: Distributed Neurons

  • 把 lane dispatch 接成 worker pool，不是排隊假並行。
  • remote VPS/LAN shards 做 non-blocking exploration。
  • score ledger 直接影響下一輪 neuron activation。

Phase 2D: Security Muscle

  • 把 monster-doctor 擴到安全診斷：secret、auth、XSS、billing、permission、supply chain。
  • 只做防禦與 owner-approved scope，不碰未授權攻擊。
  • 安全發現寫回 UMA，變成下次的快速防禦反射。

判斷標準

算真正加速

  • 更快找到第一個有用問題定位。
  • 少呼叫模型、少重掃檔案、少重複上下文。
  • 第一次任務也能靠 UMA/RAG/工具並行縮短等待。
  • 使用後的結果會寫回，下一次更快。

不算真正加速

  • 只把已生成內容從 cache 拿出來，卻宣稱冷啟動快百萬倍。
  • 啟動更多神經元但讓 hot path 變慢。
  • 跨專案污染 UMA 記憶。
  • 用模型呼叫遮掩 deterministic tool 可以解的問題。
