一行定義

Neuron Mercury 是電腦的軟體神經系統。 它把專案、檔案、模型、服務、工具與使用者意圖轉成狀態場；不是每次從零開始思考，而是先知道哪裡變了、哪條路最短、哪個 neuron 應該醒來。

總架構

1. Sensory Layer

監聽 cwd、git root、檔案 digest、GPU/CPU/記憶體、provider spend、resident 狀態。

2. UMA / RAG Memory

每個專案獨立 namespace，檔案拆 semantic pages，建立 hot pages 與 symbol table。

3. Rosen Bridge Map

把任務入口折疊到已知出口：工具、檔案、風險、成功路徑、驗證路徑。

4. Rosen Pair Runtime

local mirror 與 remote sentinel 形成 paired state；不變 replay，變了 correction pulse。

5. Sparse Neuron Scheduler

500 neurons 不全跑，依 route、score、budget、risk 喚醒少量 lanes。

6. Proof / Guard Layer

bench、coherence、spend guard、resident、monster proof 防止自爽加速。

Runtime 流程

A. 任務進來

解析使用者意圖、目標檔案、風險家族、專案 namespace、目前硬體狀態。

B. 狀態場查詢

先讀 Rosen Pair digest。如果 unchanged，跳過探索；如果 changed，只喚醒 correction route。

C. Bridge 折疊

從任務入口選 top Rosen bridges，連到 UMA pages、Code Cortex symbols、spend guard、monster doctor。

D. 稀疏神經元

只啟動相關 lanes：retrieval、risk、accelerate、verify、judge、synthesis。

E. 產出與寫回

輸出 evidence packet、診斷、patch plan 或 cached response，並寫回 task memory / pair pulse / bench trend。

F. 防自爽驗證

所有 claims 必須經 bench、resident endpoint、coherence guard、night runner 持續驗證。
