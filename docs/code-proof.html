從任務到有用結果的狀態場路徑

投資人需要看到的是「為什麼它會快」，不是看到內部函式。下面這條圖就是產品核心。

01Task enters

使用者或 agent 丟進一個工作，不直接把整包丟給大模型。

02State sensing

先看本地狀態、記憶、風險、可用路徑與是否有變化。

03State bridge

把模糊任務接到已驗證的工作路徑，縮短探索距離。

04Sparse wake-up

500 個可能性裡，只喚醒少數有用神經元。

05Evidence first

先產生 evidence packet / diagnosis / proof，不等慢模型。

06Writeback

把有效路徑寫回，下一次從更近的位置醒來。

公開展示 vs. 私有護城河

公開給投資人看的

產品能力、證據鏈、速度改善、runtime readiness、可重跑 artifacts。 這些建立信任，讓人知道它不是簡報。

不能放到公開頁的

內部決策規則、權重、執行接線、檔案結構、介面細節、完整 prompt/策略。 這些才是底牌。

一句話定位

Neuron Mercury does not make models bigger. It makes computers remember how work moves.

Neuron Mercury 不是把模型做大，而是讓電腦記得工作是怎麼流動的。這才是產品化敘事的中心。
